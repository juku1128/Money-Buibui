📋 功能架構總覽
04 / 10
全站六大核心功能模組「粗略總覽：麻雀雖小，五臟俱全」
🛡️
1. 本機紀錄特色 (Local-First)
完全免註冊！資料 100% 保存在個人電腦瀏覽器，支援多手帳切換與一鍵 JSON/CSV 備份。
🏠
2. 畫面首頁 (Dashboard)
日系手帳 Bento 便當盒佈局，圍巾萌柴柴助手根據真實財務數據給予溫暖金句建議。
📊
3. 理財規劃 (Planning)
內建 50/30/20 法則、六個罐子理財法與自訂比例即時試算，整數分配零浮點誤差。
📝
4. 記帳視圖 (Transactions)
三層級動線：置頂每日流水帳、清楚標註【每日收支】、下方整合每月收支與預算扣抵。
📈
5. 消費分析 (Analysis)
直觀的收支長條圖、支出分類圓餅圖、近半年開銷趨勢，以及 80%/100% 預算警示燈號。
💸
6. 借貸與話術 (Debts)
借款扣抵狀態機、9 大風格 180 款情境催款話術、經濟學垃圾話，以及極限地獄催款模式！
