功能實測三：雙重視角記帳（每日聚焦當日 ＋ 每月篩選流水帳）

🌿 頂部【檢視每日記帳項目】（聚焦當日）

純粹只呈現所選當日（11/02）明細（學餐便當 -110、珍奶 -65），支援日曆與「◀ 前一天」「後一天 ▶」切換，乾淨俐落！

🏷️ 當日收支即時小計徽章

日期橫條右側即時彙整「當日支出 NT$ 175 │ 收入 NT$ 0 │ 結餘 -175」，每一天的錢包動態隨時一目了然。

🗓️ 下方【檢視每月收支】（全月可篩選帳本）

整合月度總覽、分類預算執行進度條，並能依照「全部/支出/收入」與各分類膠囊篩選整個月的歷史流水帳！

依據使用者回饋重構動線：先看每日細項，再看全月預算，邏輯最清晰！ 下一頁：借貸管理與催款話術 👉
