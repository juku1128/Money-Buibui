程式新手如何克服卡關？「我定邏輯審美，AI 幫寫代碼驗收」
STEP 01
痛點發想與定義
不追求天花亂墜的複雜功能，專注解決自己真實遇到的痛點：記帳麻煩、朋友欠錢不知道怎麼討。
💡 決策：不做雲端登入，做純前端 Local-First
STEP 02
零依賴輕量架構
初學者常被 npm、Node 環境配置折騰。我們選擇原生 HTML5 + CSS + JS，雙擊就能跑！
⚡ 成果：跨平台零依賴，點開即用
STEP 03
人機協同 Pair-Coding
我給需求與審美修正（如：拿掉迷因回歸日系手帳、新增地獄烈焰），AI 即時重構並補齊邏輯。
🤖 角色：我是導演，AI 是得力助教工程師
STEP 04
測試驅動安心交付
新手最怕改了 A 壞了 B！我們建立了 34 項自動化測試，每次修改按下測試立即保證 0 錯誤。
🧪 信心：34 項單元測試 100% PASS
🤝
新手的真實體悟：不用害怕自己是初學者！只要有清楚的問題意識，善用 AI 工具結對編程，並堅持做好單元測試，新手也能獨立完成一個具備商業級完成度的好專題！
開發技術棧：HTML5, CSS3 Animations, 原生 ES6+ JavaScript, Python 3 輕量本機伺服器 零外部金鑰依賴
