Money-Buibui — 大學生的可愛理財手帳管家

期中專題成果報告書

專案基本資訊

  • 專題名稱：Money-Buibui — 大學生的可愛理財手帳管家
  • 專案代號：money-buddy
  • 專題類型：Web 應用程式（前端原生 Local-First 架構）
  • 技術棧：HTML5, CSS3 (Tailwind CSS CDN + 自訂手帳動畫 Tokens), 原生 JavaScript (ES6+ 模組化), Python 3 輕量伺服器, Chart.js, Lucide Icons

一、做什麼 (What)

1. 核心動機與痛點

大學生面臨日常零用錢、打工收入有限的挑戰，市面上的傳統記帳軟體通常存在三大痛點：

  1. 冰冷生硬、說教感重：介面缺乏溫度，連續記帳幾天便因繁瑣或無趣而放棄。
  2. 個資疑慮與註冊門檻：強迫綁定手機號碼、Email 甚至連動銀行帳號，對於大學生產生沉重心理負擔。
  3. 借貸尷尬難開口：大學校園中同學聚餐代墊、借筆記錢是常態，但欠款難追、忘記還錢又礙於友情難以啟齒。

2. 解決方案

Money-Buibui 是一款專為大學生設計的「可愛日系手帳風理財管家」：

  • 溫暖圍巾萌柴柴助手（Shiba Buddy）：根據真實收支數據給予情緒反饋與幽默溫馨分析，絕不說教。
  • 清晰三層級記帳視圖：最上方置頂「每日記帳項目」流水帳、每日標題清楚呈現「【每日收支】」、下方整合「每月收支」與分類預算膠囊。
  • 三大經典理財法試算：內建 50/30/20 法則、六個罐子理財法與自由自訂比例，自動計算合理金額分配。
  • 情境式催款訊息生成器：支援 9 大催款風格（含委婉、可愛、幽默、荒謬經濟學垃圾話爆擊，以及極限地獄粗口與法律威嚇），內建 180 款高變化度情境話術，並具備全螢幕震動、烈焰與惡魔現身的地獄模式視覺特效！
  • 零個資（Zero-PII & Local-First）：完全免註冊，所有資料 100% 留存在使用者本地瀏覽器，支援多手帳身分隔離與 JSON/CSV 一鍵匯出匯入。

二、給誰用 (Target Audience)

  1. 大學生族群（主要使用者）：
  • 預算有限、需要掌控每月生活費與打工薪水的大學生。
  • 經常和同學聚餐、合資代墊飲料或餐費，常遇到朋友忘記還錢的社交情境。
  1. 新手理財族：
  • 過去覺得記帳枯燥、需要視覺儀式感與溫暖回饋以建立持久習慣的使用者。
  1. 重視隱私與無負擔的使用者：
  • 不希望將個人收支上傳至雲端、不願透露手機號碼與信箱的使用者。

三、怎麼做 (How)

1. 系統架構與設計理念

本專案堅持 Local-First（本地優先） 與 Zero-Dependency（零外部重構建依賴） 原則：

  • 前端呈現層 (index.html, css/style.css)：

採用日系文創手帳視覺設計（抹茶綠、櫻花粉、珊瑚橘手繪紙膠帶、網點與圓角 Bento 卡片排版），並針對地獄模式注入全螢幕震動、黑曜石深淵熔岩背景、SVG 火焰火舌動態與惡魔柴柴互動動畫。

  • 資料存取層 (js/storage.js)：

封裝 LocalStorage 介面，支援多身分（Profile）手帳切換、資料防呆校驗與自動示範資料種子生成，完全零雲端個資風險。

  • 情境話術引擎 (js/scripts_data.js)：

內建 9 大風格、每種風格 20 款、共 180 款完整的情境話術動態演算庫，支援自動帶入欠款人暱稱、金額、拖欠天數、代墊事由與生活情境。

  • 吉祥物互動核心 (js/mascot.js)：

純 SVG 手繪向量角色（圍巾萌柴柴、惡魔三叉戟柴柴、燃燒柴柴、警示驚訝柴柴），依據本月儲蓄率、預算超支情況與借貸逾期狀況，即時提供溫暖理財錦囊。

  • 主控制器 (js/app.js)：

管理 SPA（單頁應用程式）路由跳轉、圖表即時繪製（Chart.js）、預算連動即時扣抵、地獄視覺控制與退場機制。

  • 本機展示伺服器 (server.py)：

基於 Python 3 內建標準庫 http.server，無需安裝 npm 或額外 Python 套件，雙擊或單行指令即可立即啟動。

3. 雙 AI 協同開發工作流（ChatGPT 提示詞精煉 ＋ Antigravity 實體工程）

本專題展現了進階的「雙 AI 互補人機協作模式」，將 AI 依擅長領域分工：

  1. 前期創意發想與提示詞精煉（ChatGPT）：
  • 學生作為產品負責人（Product Owner），先與 ChatGPT 進行深度需求探討、角色性格定義（陪伴型暖柴柴 vs 搞笑催款）、功能邊界收斂，並共同精煉出結構嚴謹的「系統開發提示詞（Prompts）」，包含驗收標準（Acceptance Criteria）、資料模型防呆規範與經濟學垃圾話等特色亮點。
  • 完整對話歷程公開連結：ChatGPT 對話紀錄（補完記帳提示詞）
  1. 軟體架構落地、實作開發與自動化測試（Antigravity / 實實）：
  • 學生將精煉後的系統提示詞交付給 Google DeepMind Antigravity Assistant（實實）執行代碼實體化。
  • 實作原生 ES6+ 模組、Local-First 零個資存取引擎、SVG 動畫元件、180 款話術字典，並撰寫 test_app.py 34 項自動化單元測試，達成 100% 綠燈覆蓋與 16:9 投影片生成。

四、怎麼測 (Verification)

1. 自動化測試體系 (test_app.py)

專案建構了完整的自動化測試套件，涵蓋 34 項端到端與單元邏輯驗證，執行時間僅約 0.03 秒：

  • 核心檔案與架構完整性檢驗（Test 1）：確保所有 HTML、CSS、JS、伺服器腳本齊備。
  • 理財規劃演算法試算（Test 2-3）：
  • 驗證 50/30/20 分配比例加總為 100% 且 NTD 整數試算無浮點誤差。
  • 驗證六個罐子理財法（55/10/10/10/10/5）比例與分配邏輯。
  • 借貸還款狀態機（Test 4）：
  • 驗證多次部分還款扣抵與狀態轉移（unpaid ➔ partial ➔ paid）。
  • 話術資料庫與參數代換（Test 5, 6, 21）：
  • 驗證 9 大風格均具備至少 20 種獨立話術（共 180 款）。
  • 驗證 {name}, {amount}, {days} 參數精準代入無遺漏。
  • 預算連動扣抵與多層警戒判定（Test 7-13）：
  • 支出在 0~79% 呈現綠色安全進度。
  • 達 80% 觸發溫柔提醒。
  • 達 100% 或超出時呈現紅色警示並動態計算超額金額。
  • 月份隔離與篩選（Test 12, 14）：
  • 驗證不同月份預算互相獨立，不跨月污染。
  • 視覺規範與元素結構驗收（Test 23-34）：
  • 驗證導航順序：首頁 ➔ 理財規劃 ➔ 記帳 ➔ 消費分析 ➔ 借貸與話術。
  • 驗證記帳頁「每日記帳項目」置頂、「【每日收支】」清晰標註。
  • 驗證地獄模式動態火焰（flameLick）、惡魔柴柴（devil）、螢幕微震（hellScreenShake）與滅火機制。
  • 驗證完全移除任何令人混淆的 API 金鑰連線標籤。
