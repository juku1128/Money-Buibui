# Money Buddy — 大學生的可愛理財管家 🐾

> 「讓記帳變得有趣，讓理財變得簡單。」  
> 一本兼具溫暖手帳插畫風格、三種理財架構分配、預算警示與催款神器的 Web 應用程式。

---

## 🌟 專案特色

1. **零個資隱私設計（Zero-PII & Local-First）**：
   - 無需輸入 Email、手機號碼或真實個資。
   - 資料 100% 妥善保存在使用者的瀏覽器本地端，伺服器不留存任何收支與密碼，完全零個資洩漏風險。
   - 支援「多手帳身分切換」，同一台裝置可建立多個同學的手帳並互相隔離。
2. **柴柴理財小助手（Shiba Buddy）**：
   - 根據本月的實際記帳數據，給予動態的情緒頭像（開心、沉思、驚訝警示、地獄怒火）與不說教的溫暖理財建議。
3. **三大理財規劃架構即時試算**：
   - **50/30/20 法則**：50% 必要、30% 想要、20% 儲蓄投資。
   - **六個罐子理財法**：55% 生活必需、10% 長期儲蓄、10% 財務自由、10% 教育成長、10% 休閒娛樂、5% 贈與分享。
   - **自訂比例**：自由新增項目、滑桿調整百分比、防呆 100% 總和校驗。
   - 即時計算分配金額（NTD 無浮點數誤差）、圓餅圖展示與架構差異對比表。
4. **日常收支管理與圖表分析**：
   - 記帳 CRUD（收入／支出、分類、金額、日期、備註）。
   - 預設 14 種大學生專屬分類，支援自由自訂分類。
   - 月度收支柱狀圖、支出甜甜圈圖、近半年消費趨勢折線圖。
   - 分類預算管理：達 80% 溫柔提醒、超過 100% 醒目通知。
5. **借貸管理與 8 大還錢話術產生器**：
   - 借款紀錄 CRUD、多次部分還款扣抵、剩餘欠款自動計算、逾期標籤提示。
   - 8 大話術風格（每種風格至少 2 個不同版本，一鍵帶入參數）：
     1. 🌱 溫柔提醒型
     2. 🐾 可愛撒嬌型
     3. 🎪 幽默搞笑型
     4. 👔 正式禮貌型
     5. 🎯 委婉堅定型
     6. ⚡ 強硬禮貌型
     7. **🔥 粗口暴躁型（地獄催款模式）**
     8. **⚖️ 法律威嚇型（地獄催款模式）**
   - 地獄催款模式專屬視覺、火焰動效與防翻船確認視窗。
   - 一鍵複製話術到剪貼簿。
6. **一鍵載入示範數據（Demo Mode）**：
   - 專為作業展示設計！點擊「載入示範手帳」，立刻自動填入大學生一個月的生活費、打工薪水、日常外食、預算超支與多筆朋友借貸，一秒看見完整圖表與話術功能。
7. **備份與資料轉移**：
   - 支援將手帳完整資料一鍵匯出為 `.json` 備份檔，或將記帳明細匯出為 `.csv` 試算表。

## 🚀 快速啟動方式

本專案採用零依賴設計，只需 macOS 內建的 Python 3 即可立刻啟動：

### 方法 1：使用本機 Python 伺服器啟動（推薦）
在終端機執行：
```bash
python3 server.py
```
啟動後打開瀏覽器前往：
👉 **http://localhost:8000**

### 方法 2：直接雙擊開啟
直接使用任何瀏覽器（Chrome, Safari, Edge）開啟專案資料夾內的 `index.html`，所有功能（記帳、圖表、話術、本機儲存）皆可正常運作！

### 方法 3：分享給同學手機試用
只需將本專案推送到 GitHub 並開啟 **GitHub Pages**，或上傳至 **Vercel / Netlify**，即可得到一個公開網址，同學用手機瀏覽器點開就能直接當手帳使用！

## 🧪 執行自動化測試

本專案附帶完整的單元測試套件：
```bash
python3 test_app.py
```
測試涵蓋：
- 靜態核心資源與模組存在性
- 50/30/20 與六個罐子理財算法
- 借貸扣抵與狀態機切換（未還／部分還款／已結清）
- 8 大催款話術庫與地獄模式旗標
- 預算 80% 與 100% 警示門檻判定
